## 1. Start studying

Start with the familiar Mie image pipeline: pose a question, define terms, derive the mechanism, then transfer it to LLMs. Allow 45 minutes for a deep unit and about 25 for other core units; this includes calculations, predictions and explanation, not reading alone.

Budget 20 hours: 12 for understanding and derivation, 5 for closed-book recall and transfer, and 3 for weak spots. Read the narrative on the first pass; jump to the recap when reviewing. Answer before revealing the solution. A checked unit remains your self-assessment, not an automatic claim of mastery.

## 2. How to use the graph

The hub is the interview target. Direction nodes represent high-performance computing, chip architecture, C++ systems, AI engineering, and AI infrastructure; concept nodes can be shared by multiple directions. The graph is collapsed by default and is for navigation and one-hop relationships, not a prerequisite for the study flow.

Follow **decomposition → scaling → memory hierarchy → Roofline → GPU execution → operators → concurrency and distributed systems** on the first pass. Prerequisite nodes identify necessary foundations; graph edges indicate related topics, not a demand to jump back and forth.

## 3. Evidence labels

Source nodes are deliberately typed. A job description supports topic relevance; a personal interview report supports a remembered question; a historical HackerRank page supports only a historical test format; and the user-provided synthesis is a navigation aid that still requires source-level verification.
