## 1. 动机

前面的附录课程给出了精确恒等式和限定范围的定理。本短课程汇集了常被混淆的表达力结果。“通用逼近器”涉及定义域上的函数类。“Lipschitz”涉及对扰动的敏感性。“TC0”涉及一种形式化的有限精度计算模型。NNGP 和 NTK 涉及无限宽极限。μP 涉及参数化和超参数迁移。这些是不同的维度。

## 2. 作用域映射

以下陈述是本课程所使用的论断：

| 陈述 | 状态 | 条件与注意事项 |
| --- | --- | --- |
| 带有位置编码的 Transformer 可近似任意连续序列到序列映射 | **定理，限定范围** | 需满足 Yun 等人提出的紧域及架构/宽度假设；并非有限预算下的质量保证 |
| 标准点积自注意力机制在每一个无界输入域上都是 Lipschitz 连续的 | **如所述为假** | Kim 等人证明了其在无界域上的非 Lipschitz 性；L2 注意力在其假设下具有有界性结果 |
| 对数精度 Transformer 包含于一致 $\mathrm{TC}^0$ 中 | **定理，形式化模型** | 精度、深度、规模以及输入/输出约定至关重要 |
| 思维链（Chain-of-thought）增强了表达能力 | **定理/论断，依赖模型** | 中间生成的 token 增加了计算步骤；结果取决于其数量及形式化解码器模型 |
| 无限宽注意力机制具有 NNGP/NTK 描述 | **定理，渐近性质** | 多头与宽度极限已明确指定；有限模型仅为近似 |
| μP 使超参数能够跨规模迁移 | **经验/理论处方** | 在 μP 参数化及测试范围内支持迁移稳定性；并非通用优化器定理 |

## 3. 简短结论

**定理，范围限定：通用逼近。** [Yun 等人](https://arxiv.org/abs/1912.10077) 证明了具有紧支集的连续置换等变序列到序列函数的通用逼近性，并表明位置编码消除了任意连续序列到序列函数在紧域上的置换等变限制。该结果明确了自注意力机制与前馈层的不同作用。它并未断言在有限数据上训练的固定深度、固定宽度模型能很好地拟合所有目标。

**定理，范围限定：稳定性。** [Kim, Papamakarios 和 Mnih](https://arxiv.org/abs/2006.04710) 表明标准点积自注意力机制在无界输入域上不是 Lipschitz 连续的，并提出了一种基于 L2 注意力的 Lipschitz 替代方案。QK-norm 和 Pre-LN 是受稳定性动机驱动的有效设计选择，但这种工程理由属于**类比，已标注**；该论文的定理仅针对指定的注意力映射和定义域。

**定理，形式化模型：电路复杂度。** [Merrill 和 Sabharwal](https://arxiv.org/abs/2310.07923) 分析了对数精度 Transformer 以及生成中间标记的影响。没有长草稿纸的前向传播与允许生成并消耗中间标记的解码器具有不同的计算预算。因此，“CoT 使模型更智能”这一说法过于宽泛。严谨的表述明确指出了步数、精度、深度和复杂度类别。

**定理，渐近分析：NNGP/NTK。** [Hron 等人](https://arxiv.org/abs/2006.10540) 推导了无限宽度注意力极限。在他们的设定中，随着头数的增加，多头注意力机制趋近于高斯过程行为，具有注意力 NNGP/NTK 核。这是一种渐近分析，并非声称有限 LLM 完全等同于高斯过程。

**处方，标注为近似/工程。** [Tensor Programs V](https://arxiv.org/abs/2203.03466) 研究了 μP 和零样本超参数迁移。其实用信息是，在测试设置中，较小的 μP 参数化模型可以为较大模型指导超参数选择。该理论描述了缩放行为；它并未消除验证目标模型的必要性。

| Hopfield 更新等于作用域注意力步；容量呈指数级 | 定理（作用域限定） | 裸关联更新；在分离条件下概率 $\Omega(d)$ 下界，而非无条件 $\Theta(e^d)$ |

| 纯注意力导致秩双重指数级坍缩 | 定理（作用域限定） | 无残差、无 FFN 保护、权重有界、自注意力反馈 |
| 注意力动力学是 Wasserstein 梯度流 | 定理（依赖 regime） | 原始对称和 Sinkhorn regime 具有势函数；行 Softmax 通常不具备 |

## 5。交互式可视化

本简短综述未新增任何组件。V-M7-a 至 V-M7-e 是附录的计算对象。其验证构成了适当的数值证据：有限恒等式直接进行测试，而限定范围的定理则保留其假设与渐近极限。

## 6。结语

**反直觉的问题。** 一个模型类如何既能成为通用逼近器，而形式上的有限精度 Transformer 却存在电路复杂度上限？

**解答示例。** 这些陈述量化了不同的资源。通用逼近定理允许在紧集域上调整架构、宽度、深度和参数。TC0 结果则固定了形式化的深度/精度/规模范围，并研究该范围内的计算能力。思维链（Chain-of-thought）改变了串行生成步骤的数量。由于量词和计算预算不同，因此不存在矛盾。

**作业 A-M7。** 完成附录报告，将你在定理/逼近/类比表中使用的每一个主张填入其中。附上来自 D-M7.1、D-M7.2、D-M7.3 和 D-M7.4 的通过输出，在 V-M7-b 上比较 row-softmax 与 Sinkhorn，在 V-M7-c/V-M7-d 上比较检索规则与在线规则，并记录哪些主张是经验性的、渐近的还是精确的。

**核心检查。** 表达能力、稳定性、电路复杂度、无限宽核以及缩放参数化是互补的视角。定理的条件是其内容的一部分；没有任何一个可以替代对具体训练模型的评估。
