# Physics lessons 1–2 Implementation Plan

> **For agentic workers:** execute `docs/superpowers/plans/2026-09-18-physics-01-02/task-01-*.md`
> … `task-13-*.md` strictly in number order, one at a time. Read each task file completely
> before starting it. The executor prompt is `EXECUTOR-PROMPT.md` in the same directory.

**Goal:** two offline bilingual lessons — `dist/physics-01-traveling-waves.html` and
`dist/physics-02-standing-waves.html` — where the standing-wave lesson derives the
harmonic series from a real finite-difference PDE solution instead of quoting a formula.

**Architecture:** the framework in `framework/` already exists and is not modified by this
plan. Each lesson is a folder under `subjects/physics/` holding `index.html`, `main.tsx`,
`meta.json`, `lesson.en.mdx`, `lesson.fi.mdx`, `terms.json`, its figures and its tests.
Pure numerics live in plain `.ts` modules with no DOM, tested on their own; components only
draw them.

**Tech Stack:** Vite 8, Preact, MDX (remark-math + rehype-katex with `output: 'mathml'`),
vite-plugin-singlefile, Vitest 5 + jsdom, tsx. No new dependencies.

**Spec:** `docs/superpowers/specs/2026-09-18-physics-acoustics-design.md`

## Global Constraints

Every task inherits these. They come from the framework spec and are not negotiable.

- The built file opens from `file://` by double-click: zero network requests, zero console
  errors, no CDN, no web fonts, no absolute asset paths, no runtime `fetch`.
- Maths is MathML only. Never import KaTeX CSS or fonts.
- Each built lesson stays under 1.5 MB.
- Readable text goes in MDX **children**, never in attributes.
- Figure strings go through `pick({ en, fi })`; canvas colours through `cssVar('--token')`.
- Animation only through `SimCanvas` / `useAnimationFrame`, so it pauses off screen.
- `localStorage` only inside `try/catch`.
- Lesson → framework imports are relative: `../../../framework/…`.
- Tests sit beside the code they test, named `*.test.ts` or `*.test.tsx`.
- jsdom has no canvas: `getContext` returns `null`. Components must render without it and
  tests must never assert pixels.
- No new npm packages. No changes to any file under `framework/`, `scripts/` or
  `subjects/math/`.
